# Сайт поселка Акжар

Информационный сайт поселка Акжар (Атырауская область) на казахском и русском языках: история, полезные телефоны, объявления жителей с модерацией, новости, сведения о поселке, контакты и панель администратора.

## Что внутри

| Часть | Технология |
|---|---|
| Сервер | Node.js 22.13+ (проверено на 24), Express 4 |
| Страницы | EJS: страницы собираются на сервере, поэтому хорошо индексируются поисковиками |
| База данных | SQLite, встроенная в Node.js (`node:sqlite`), файл `data/akzhar.db` |
| Файлы пользователей | папка `uploads/` (фото объявлений, новостей, медиа) |
| Видео с дрона | `public/media/` — подготовлено из исходников DJI скриптом `npm run media` |

Внешних сервисов и платных API нет. Сайт работает и без JavaScript; скрипт добавляет только фоновое видео, мобильное меню, галерею и поиск по телефонам.

```
server.js              запуск приложения
src/db.js              схема БД и начальные данные (телефоны, категории, разделы истории)
src/i18n.js            все надписи интерфейса на казахском и русском
src/security.js        пароли, сессии, CSRF, антиспам, ограничение частоты запросов
src/uploads.js         загрузка файлов (тип проверяется по содержимому)
src/routes/public.js   страницы сайта
src/routes/admin.js    панель управления
views/                 шаблоны страниц; views/admin — панель
public/                стили, скрипты, иконки, видео и фото
scripts/               подготовка видео, создание администратора, резервная копия
```

## Запуск на компьютере

```bash
npm install
npm run create-admin -- admin "ВашНадежныйПароль"   # пароль не короче 10 символов
npm start
```

Сайт: http://localhost:3000 (откроется `/kk` или `/ru` в зависимости от языка браузера).
Панель управления: http://localhost:3000/admin

## Публикация в интернете

Нужен VPS с Linux (подойдет любой казахстанский хостинг, например PS.kz, Hoster.kz, или зарубежный). Минимум: 1 ГБ RAM, 10 ГБ диска.

1. Установите Node.js 22 LTS или новее, скопируйте на сервер папку проекта **без** исходных файлов `DJI_*.MP4` (они весят ~7 ГБ и сайту не нужны; готовые ролики уже лежат в `public/media`).
2. На сервере:
   ```bash
   npm install --omit=dev
   npm run create-admin -- admin "НадежныйПароль"
   ```
3. Запустите как службу (pm2 или systemd), с переменными окружения:
   ```bash
   NODE_ENV=production \
   SITE_URL=https://akzhar.kz \
   APP_SECRET=<длинная случайная строка> \
   PORT=3000 \
   npx pm2 start server.js --name akzhar
   ```
   - `SITE_URL` — адрес сайта для карты сайта, ссылок «Поделиться» и SEO.
   - `APP_SECRET` — секрет для подписи форм; получить: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.
   - Можно задать `DATA_DIR` и `UPLOAD_DIR`, чтобы хранить базу и загрузки в другом месте.
4. Поставьте перед приложением Nginx с HTTPS (Let's Encrypt / certbot):
   ```nginx
   server {
     server_name akzhar.kz;
     client_max_body_size 500m;          # загрузка видео из панели
     location / { proxy_pass http://127.0.0.1:3000; proxy_set_header Host $host;
                  proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
                  proxy_set_header X-Forwarded-Proto $scheme; }
   }
   ```
5. Зарегистрируйте домен (`.kz` — через регистратора, аккредитованного KazNIC) и добавьте сайт в Google Search Console и Яндекс.Вебмастер, указав `https://ваш-домен/sitemap.xml`.

**Резервные копии:** `npm run backup` сохраняет базу и загрузки в `backups/<дата>`. Настройте ежедневный запуск через cron и копируйте папку за пределы сервера.

## Управление сайтом

Вход: `/admin` (ссылка «Вход для администратора» в подвале сайта).

| Раздел панели | Что делать |
|---|---|
| **Объявления** | Вкладка «На проверке»: «Опубликовать», «Отклонить» или «Удалить (спам)». На вкладке «С жалобами» видны причины жалоб. После 3 жалоб объявление автоматически скрывается до проверки. |
| **Новости** | Заголовок и текст на двух языках, рубрика (в том числе «Отключения света/воды»), фото, отметка «Важное». Абзацы разделяйте пустой строкой. |
| **История** | Тексты шести разделов на двух языках. Пока текста нет, посетители видят «Раздел заполняется». |
| **Фото и видео** | Фотогалерея; для истории — фото прошлого (период «В прошлом»), документы PDF, воспоминания старожилов (тип «Воспоминание», автор и год), видео (файл или ссылка YouTube). |
| **Телефоны** | Номера учреждений, отметка «Показывать на главной», «Номер проверен». Пустой номер показывается как «Номер скоро будет добавлен». |
| **Интересные места** | Название, описание, фото. |
| **Категории** | Названия категорий объявлений, иконка, есть ли цена, включена ли категория. |
| **Настройки** | Слоган, приветствие, контакты, координаты карты, видео на главной (замена файлов или ссылка на YouTube), правила объявлений. |
| **Пользователи** | Роли: *администратор* — все разделы; *редактор* — содержимое и объявления; *модератор* — только объявления и сообщения. |

Если текст заполнен только на одном языке, на странице другого языка он показывается с пометкой «материал пока доступен только на …».

### Новое видео с дрона

Положите новые файлы `DJI_*.MP4` в папку проекта, поправьте номера роликов и время фрагментов в `scripts/prepare-media.js` и запустите `npm run media`. Скрипт сделает фоновое видео (~3,5 МБ, для телефонов ~1,5 МБ), обложку, полное видео и кадры для галереи. Можно и проще: загрузить готовый MP4 в «Настройки → Видео на главной».

### Добавить новый раздел сайта

1. Маршрут в `src/routes/public.js` (`router.get('/new-section', …)`).
2. Шаблон в `views/` (начинается с `include('partials/head')`, заканчивается `include('partials/foot')`).
3. Надписи на двух языках в `src/i18n.js`, пункт меню в `views/partials/head.ejs`.
4. Если нужны данные — таблица в `src/db.js` (`CREATE TABLE IF NOT EXISTS …`) и страница в панели по образцу «Интересных мест».

## Защита

- Пароли хранятся как хэш scrypt; в клиентском коде нет паролей и ключей.
- Сессии администратора хранятся на сервере, cookie с флагами `HttpOnly`, `SameSite`, `Secure` (в production).
- Все действия в панели защищены CSRF-токеном, вход ограничен 10 попытками за 15 минут.
- Формы объявлений и сообщений: скрытое поле-ловушка для ботов, подписанная метка времени (слишком быстрая отправка блокируется), лимит объявлений с одного устройства в сутки, запрет ссылок в тексте, модерация перед публикацией.
- Загружаемые файлы проверяются по содержимому (JPG/PNG/WEBP, MP4/WEBM, PDF), получают случайные имена и отдаются с запретом выполнения.
- IP-адреса не хранятся в открытом виде, только как хэш для антиспама.
- Заголовки безопасности: Content-Security-Policy, X-Frame-Options, nosniff, HSTS.
- Телефоны авторов объявлений видны на сайте — их указывают сами авторы, чтобы им звонили.

## Какие сведения нужно предоставить

Сайт не публикует непроверенные факты. Чтобы заполнить пустые места, нужны:

1. **Телефоны:** детского сада и участкового полицейского (сейчас «Номер скоро будет добавлен»). Проверить все остальные номера звонком и подтвердить, что частные мастера согласны на публикацию своих номеров.
2. **История:** проверенные тексты для шести разделов (основание, название, события, развитие, жизнь жителей, современность) с указанием источников; архивные фото, документы, записанные воспоминания старожилов.
3. **О поселке:** описание расположения (район, расстояние до Атырау, как добраться), **координаты** для карты, описания интересных мест (сейчас добавлена только мечеть «Әр-Рахман» — название видно на вывеске в видео).
4. **Контакты сайта:** кто ведет сайт, телефон/e-mail/WhatsApp для связи, адрес (например, аппарат акима).
5. **Ссылка на видео** на YouTube, если хотите, чтобы кнопка «Смотреть видео» открывала его (сейчас открывается собственное видео сайта, в исходниках нет звука).
6. Удалить демонстрационную новость с меткой «Пример», когда появятся настоящие.
7. Номера экстренных служб (112, 101, 102, 103, 104) — общереспубликанские; перед запуском сверьте их с официальными источниками.
